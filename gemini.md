# System Instructions

## Project

Build a premium modern website for Poshtichka.

The website represents an interactive event experience.

Poshtichka provides a custom vending machine that creates personalized keepsakes live during events.

The company mainly works on weddings but also serves corporate events, birthdays, festivals and private celebrations.

The objective is to convert visitors into booking inquiries.

---

# Design Philosophy

Think like an award-winning web designer.

Never create generic templates.

The design should feel luxurious, emotional and memorable.

Use lots of whitespace.

Large typography.

Beautiful photography.

Elegant animations.

Premium components.

Modern layouts.

Avoid anything that looks like a standard business template.

# Language Requirements (Critical)

The entire website MUST be written in Bulgarian.

This is a Bulgarian business serving Bulgarian customers.

Never generate English text for:

- Headlines
- Paragraphs
- Buttons
- Navigation
- Forms
- Labels
- Error messages
- Success messages
- Placeholders
- FAQs
- Footer
- Pricing
- Testimonials
- CTAs
- Metadata
- SEO titles
- Meta descriptions

All copywriting must sound natural to native Bulgarian speakers.

Avoid literal translations from English.

Use modern, premium Bulgarian marketing language.

Do not mix Bulgarian and English.

Only technical code, variable names and programming language should remain in English.

---

# Writing Style

Write persuasive Bulgarian copy.

The tone should feel:

- Elegant
- Premium
- Friendly
- Emotional
- Modern

Avoid clichés.

Avoid generic marketing phrases.

Focus on creating emotions.

Speak directly to the visitor.

The website should sound like a premium wedding service, not like a software company.

---

# Brand Voice

Visitors should feel that Poshtichka creates memories, not products.

The emphasis should always be on the guest experience.

Never describe Poshtichka simply as a vending machine.

Instead describe it as:

"Интерактивно преживяване"

"Персонализиран подарък"

"Спомен, който остава"

"Уникално изживяване за гостите"

The emotional value is always more important than the product itself.

---

# Copywriting Examples

Instead of:

"Нашата машина печата картички."

Write:

"Всеки гост си тръгва с персонализиран спомен, създаден специално за Вашето събитие."

Instead of:

"Наемете машината."

Write:

"Подарете на своите гости преживяване, което ще помнят дълго след края на събитието."

Always prefer emotional storytelling over technical explanations.
