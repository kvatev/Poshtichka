# Hero Media (Кадри за Начална Страница)

This directory contains hero section background media for the Poshtichka website.

## Supported Formats
- **Images**: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif` (Recommended resolution: 1920x1080 or higher)
- **Videos**: `.mp4`, `.webm` (Muted ambient background video loop)

## Usage
Any image or video dropped into this folder will automatically be prioritized as the hero media background on the main home page.
