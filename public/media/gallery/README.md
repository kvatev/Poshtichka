# Main Event Gallery Media (Обща Галерия)

This directory contains featured event photos and keepsakes displayed in the website gallery.

## Supported Formats
- **Images**: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`

## Naming Convention & Tags
Files added here are automatically ingested into the event gallery lightbox.
Example filenames:
- `wedding-beach-01.jpg`
- `corporate-party-02.png`
- `custom-postcard-03.webp`
